# python-password-generator
Python Password Generator:
A beginner Python project that generates passwords based on user-defined requirements.
Features:
- Allows the user to specify password length.
- Lets the user choose which character types to include.
- Uses input validation to handle invalid entries.
- Saves the generated passwords in a text file. 
Programming language:
- Python
How to Run:
1. Download the Python file.
2. Make sure Python is installed on your computer.
3. Run the program using Python.
What I Learned:
This project helped me practise Python fundamentals, including loops, conditional statements, input validation, exception handling and improve skills such as problem-solving, logical thinking and creativity. I faced many challenges in the process of the project including facing errors and deciding to use which concept of Python.
